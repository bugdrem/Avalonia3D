### XD2D 逆向分析（参考目标方案）
- 详见上一轮分析：.NET 9 WPF(x86) + OCCT 7.9.1 + TKOpenGl/WGL + WPF HwndHost 承载原生窗口
- 自研 C++/CLI 加固：WindowlessSafeGraphicDriver / DetachableOpenGlView / OwnedOpenGlWindow + 显式 wgl 上下文保存恢复
- 无 GPU 兜底：自带 Mesa 25.2.0 llvmpipe（x86 的 opengl32.dll + libgallium_wgl.dll），
  主程序以 `_MesaOpenGlModule/_MesaGalliumModule` 静态句柄 + LoadLibraryExW 显式加载
- 2D 输出：HLRBRep_HLRToShape 做隐藏线消除导出 2D 轮廓（打标路径上游）

### 新功能：2D/3D 视图切换（带过渡动画）+ 性能优先
- Core：`OrbitCamera` 增加 `ProjectionBlend`(0=正交/1=透视)、`CreateOrthographicGl`、`LerpMatrix`、
  `OrthoHalfHeight = distance*tan(fov/2)`（保证切换无缩放跳变）；`ScreenPointToRay` 改为**逆 VP 反投影**，
  正交/透视/混合统一；RightDirection 增加退化保护
- Core：`ViewTransitionMath`（2D 预设 yaw=0/pitch≈90°、3D 预设 45°/27°，EaseInOutCubic，最短弧角度插值，0.42s）
- Desktop：`ViewerSession.SetLayout/UpdateViewTransition`，快照携带 `FlatShade`；`SsaaEnabled` 默认 false
- 渲染：MeshFragment 加 `uFlat`（>0.995 走 uniform 分支完全跳过光照）；**光照简化为单主光+半球环境光**（去掉补光/轮廓光/高光）
- 2D 轮廓：`MeshData.BuildFeatureEdgeSegments` —— 位置量化焊接（STL 顶点不共享）+ 边遍历方向纠正绕序 + 30° 折边阈值
- UI：工具栏「2D 视图 (T)」+ T 快捷键；2D 下左键=平移、双击只平移目标；标准方位按钮自动退出 2D

### 平面着色 + 纯 2D 草图图层（14:30）

**问题1诊断：为什么我们比 XD2D「光滑」**
- 不是抗锯齿：`SsaaEnabled` 默认 false（ViewerSession 无初值时即 false），SSAA 走原生尺寸渲染
- 真正原因：teapot.obj 自带 1202 条 `vn`（每顶点平滑法线）+ 片元 `normalize(vNormal)` 逐像素 Blinn-Phong
- XD2D（OCCT 7.9.1）对无法线网格用面法线 flat shading，每三角面一个颜色 → 面片感
- 解决：`uFlatShade` uniform，片元用 `normalize(cross(dFdx(vWorld), dFdy(vWorld)))` 求面法线
  （`dot(faceN, n) < 0` 时翻转），零额外顶点数据、零额外 draw call
- ES100 无导数函数 → GlslPreprocessor 加 `#define FLAT_SHADING 0/1` 宏降级
- 实测：模型区颜色数 1333→213，相邻像素同色率 40.7%→88.8%（K 键切换）

**问题2：2D 改为纯画布图元（不再靠 3D 网格俯视冒充）**
- Core 新增 `Scene/SketchLayer.cs`：`SketchShape`（Rectangle/Circle/Polygon）、`SketchLayer`、`SketchTool`、
  `TryIntersectFloor`（射线与水平面求交，正交/透视通用）
- 关键设计：图元坐标直接定义在世界地板平面 XZ，同一份数据既是 2D 画布图形也是 3D 地板图形，
  切换无需坐标转换（不是「2D 坐标系 + 投影映射」，而是「地板草图 + 两种投影看它」）
- 三角化：矩形特判 2 三角形（质心扇会浪费成 4 个），圆/多边形质心扇；绕序保证法线 +Y
- 渲染：新增无光照 solid 通道（SolidVertex/SolidFragment + uDepthBias）；
  2D 稳态 glDisable(GL_DEPTH_TEST) 后绘制（canvas 语义、永远可见）；
  3D 稳态保留深度 + 0.0008 偏移（贴地、被模型遮挡、不与地面网格 z-fighting）
- 交互：2D + 草图工具时左键拖拽绘制（射线∩地板取世界坐标、实时预览），松开提交，
  尺寸 < 模型半径 0.5% 视为误触；与移动/标注模式互斥
- UI：工具栏「草图：关/矩形(1)/圆(2)」，右侧面板「清空 / 平面着色 / 统计」，快捷键 1/2/K，Esc 退出

**验证**
- 81 个单元测试（新增 9 个：三角化、法线朝上、地板相交、预览不入图层、包围盒）
- 真机：2D 画出矩形+圆（蓝色像素 12011），切 3D 后地板出现透视平行四边形+椭圆（1372，基线仅 4）
- 验证陷阱：图元画在模型投影内时 3D 斜视被模型挡住 → 看似「没生效」，实为正确遮挡
- 另核实 3D 取景无 bug（teapot 8 角点 NDC 最大 0.91，截图超框是图像查看器缩放错觉）

**踩坑**
- GLSL 注释里写双引号会破坏 C# verbatim string（@"..."），报 CS1002/CS1010
- GlConsts 未暴露 GL_DYNAMIC_DRAW，需在 Glx 自定义（0x88E8）
- PowerShell 里 `[ref]` 传结构体给 P/Invoke 后变量变成 Object[]，导致 `$r.Right - 328` 报
  「Object[] 不包含 op_Subtraction」；改用全屏截图 + 固定坐标基准
