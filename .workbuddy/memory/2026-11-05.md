# 2026-11-05

### XD2D 逆向分析（参考目标方案）
- 详见上一轮分析：.NET 9 WPF(x86) + OCCT 7.9.1 + TKOpenGl/WGL + WPF HwndHost 承载原生窗口
- 自研 C++/CLI 加固：WindowlessSafeGraphicDriver / DetachableOpenGlView / OwnedOpenGlWindow + 显式 wgl 上下文保存恢复
- 无 GPU 兜底：自带 Mesa 25.2.0 llvmpipe（x86 的 opengl32.dll + libgallium_wgl.dll），
  主程序以 `_MesaOpenGlModule/_MesaGalliumModule` 静态句柄 + LoadLibraryExW 显式加载
- 2D 输出：HLRBRep_HLRToShape 做隐藏线消除导出 2D 轮廓（打标路径上游）

### 新功能：2D/3D 视图切换（带过渡动画）+ 性能优先
- Core：`OrbitCamera` 增加 `ProjectionBlend`(0=正交/1=透视)、`CreateOrthographicGl`、`LerpMatrix`、
  `OrthoHalfHeight = distance*tan(fov/2)`（保证切换无缩放跳变）；`ScreenPointToRay` 改为**逆 VP 反投影**，
  正交/透视/混合统一；RightDirection 增加退化保护
- Core：`ViewTransitionMath`（2D 预设 yaw=0/pitch≈90°、3D 预设 45°/27°，EaseInOutCubic，最短弧角度插值，0.42s）
- Desktop：`ViewerSession.SetLayout/UpdateViewTransition`，快照携带 `FlatShade`；`SsaaEnabled` 默认 false
- 渲染：MeshFragment 加 `uFlat`（>0.995 走 uniform 分支完全跳过光照）；**光照简化为单主光+半球环境光**（去掉补光/轮廓光/高光）
- 2D 轮廓：`MeshData.BuildFeatureEdgeSegments` —— 位置量化焊接（STL 顶点不共享）+ 边遍历方向纠正绕序 + 30° 折边阈值
- UI：工具栏「2D 视图 (T)」+ T 快捷键；2D 下左键=平移、双击只平移目标；标准方位按钮自动退出 2D

### 修复：内置示例模型几何有问题（用户反馈）
- 现象：内置齿轮等模型顶部三角扇的边像"所有外圈点连到中心"，2D 轮廓呈放射线
- 实测：demo 齿轮 1400 面里 1080 条边相邻面夹角≈180°（绕序混乱/退化），属模型生成缺陷
- 处理：按用户要求**默认改为加载 `samples/teapot.obj`**，工具栏下拉框扫描 samples 目录动态填充（teapot 置顶），
  csproj 把 samples 复制到输出/发布目录（`Link="samples\..."`），双击 exe 即可用；内置 DemoModels 不再暴露到 UI
- 验证：茶壶 2D 轮廓干净（特征边 1578→ 仅少量轮廓线）；像素测量模型居中（bbox 中心 629,479 vs 视口 646,494）

### 验证与工具
- 72 个单元测试全绿（新增 2D/3D 数学 11 个 + 特征边 5 个）
- `tools/verify-2d3d-fullscreen.ps1`：3D/2D 截图 + 像素差异；`tools/verify-transition.ps1`：
  110ms 中间帧与两端都不同 → 确认动画是渐变的；`tools/measure-2d.py.ps1`：像素级居中测量
